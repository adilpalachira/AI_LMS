DBMS DEGREE HANDOUT

Relational Model Core Axioms:
1. Relations are set of tuples (unordered).
2. Candidate Key: Minimal superkey uniquely identifying a tuple.
3. Primary Key: Selected candidate key.
4. Foreign Key: Attribute in relation referencing Primary Key of another relation enforcing Referential Integrity.

SQL Execution Order:
1. FROM / JOIN
2. WHERE
3. GROUP BY
4. HAVING
5. SELECT
6. DISTINCT
7. ORDER BY
8. LIMIT / OFFSET
